## 📈 How I Approach Problems

For every problem, I try to understand:

**1. 🧠 Pattern**
What DSA pattern does this problem use?

**2. 💡 Logic**
Why does the solution work?

**3. ⏱️ Complexity**

**4. 🔄 Optimization**
Can the solution be improved?

**5. 📝 Review**
Can I solve a similar problem independently?
